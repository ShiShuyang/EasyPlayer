## 安装、升级和卸载

测试在私有 Windows 注册表 hive、自定义安装目录和独立开始菜单目录中进行。交互验证使用独立桌面。隔离安装器使用真实 NSIS 指令，额外引导代码只用于测试隔离。1.0.3 对照使用原发布包提取的程序文件和旧安装逻辑。两版原始安装器均未直接在日常系统注册表上执行。

- 首次安装通过了交互选目录和静默 `/D=` 两条路径。
- 从自定义目录 A 的 1.0.3 升级时，交互与静默运行即使传入另一目录 B，也都在 A 就地完成。交互向导跳过目录和文件关联页。逐项检查了 19 种格式的候选记录、原有选择和备份，以及右键菜单、COM 命令、开始菜单快捷方式目标和系统卸载入口。
- 把新版卸载器复制到另一目录执行，交互提示显示当前有效安装位置，静默退出码为 3。原安装的共享入口和文件仍有效。登记项缺失时也会拒绝卸载。登记路径改变大小写并附加 `\.` 时，原目录仍能正常卸载。
- 锁住替换顺序靠后的文件再升级，安装器以退出码 4 中止，已替换的文件回滚，原有共享入口可用。
- 全新安装与升级后的文件清单均逐文件核对了发布负载的 SHA-256。统计目录体积时，使用 NSIS 为交付包实际生成的卸载器替换隔离测试卸载器。日常安装仍登记在 `C:\Program Files\EasyPlayer`，版本仍为 1.0.3。

## 播放验证与边界

在测试安装目录启动了交付版 `EasyPlayer.exe`，确认主窗口出现并正常关闭。为驱动控件、检查视频帧和隔离用户偏好，功能测试启动器在相同的冻结模块和运行库上增加了一个测试启动钩子，播放器入口和业务源码保持原样。测试进程的 PATH 只含 Windows 系统目录，清除了开发用 Qt、QML 和 Python 环境变量。

- Ctrl+O 打开 Windows 原生文件选择框，选择测试 AVI 后进入正常播放。验证了时钟推进、128 × 64 的有效解码帧和 QML 画面的非单色像素。
- 点击全景按钮后，OpenGL 上下文有效，着色器取得纹理，全景帧缓冲读回非单色图像。随后切回普通视频。
- 进入全屏后，控制栏在底部出现、离开后隐藏、再次移到底部重新出现。Esc 恢复窗口及控制栏。
- 打开纯音频 WAV 后，媒体时钟推进并取得 8,192 帧解码 PCM。核验了音频输出设备，未做人工听感评价。
- 检查的 40 个已加载 Qt、Python、FFmpeg 相关模块均来自测试安装目录。

尚未在独立的无开发环境 Windows 虚拟机或另一台物理机上运行原版安装包。软件 OpenGL 后备文件已保留，未强制切换到纯软件驱动单独测试。目录归属保护由新版卸载器执行，已在别处保存的历史卸载器本身不会被改写。
